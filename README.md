# Change of Subject 公式的主項變換

Interactive S2–S3 maths lesson on changing the subject when the subject appears more than once: collect the like terms, take out the common factor, then divide. In English or Traditional Chinese.

- **Key ideas 概念** – subject appearing twice, a tap-to-spot like-terms activity, animated grouping (common factor), the 4-step method and common mistakes
- **Worked examples 例題** – A = P + Prt, ax + b = cx + d, a(x − 2) = bx + 5, y = (x + a)/(x − b), animated line by line
- **Practice 練習** – 12 questions in three levels (group · collect & group · fractions); students choose each step and get feedback

Single static page: open `index.html` in a browser, or deploy to Vercel / GitHub Pages.
