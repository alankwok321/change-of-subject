# Change of Subject 公式的主項變換

Interactive S2–S3 maths lesson on changing the subject of a formula, in English or Traditional Chinese.

- **Key ideas 概念** – balance animation, inverse-operation "undo machine", rules and common mistakes
- **Worked examples 例題** – animated step-by-step solutions with working shown line by line
- **Practice 練習** – 12 questions in three levels; students choose each step and get feedback

Single static page: open `index.html` in a browser, or deploy to Vercel / GitHub Pages.
